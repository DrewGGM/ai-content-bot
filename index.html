📄 Contexto de la empresa admin

Todo lo que el bot sabe de tu empresa se edita aquí: qué hace, productos, tono, estrategia… y puedes crear archivos .md nuevos (prompts personalizados, guías de estilo, promociones) que el bot inyecta automáticamente en cada generación. Los cambios aplican de inmediato, sin tocar código.

¿Qué es esto? Un bot open-source que genera contenido de redes para cualquier marca con cualquier agente de IA (Claude Code, Codex, Gemini CLI, Qwen, Kimi, Cursor, Copilot, OpenCode, o un comando propio) o cualquier API de LLM (Anthropic, OpenAI, OpenRouter, DeepSeek, Groq, Ollama local…). Panel multi-usuario: cada miembro del equipo conecta su propia cuenta (login guiado de Claude Code con setup-token, o API keys) — las credenciales se cifran en el servidor y cada generación corre con el agente de quien la pidió. La empresa se configura 100% desde el panel: contexto, prompts propios, logos y colores. Escribe el copy con el contexto de tu empresa, genera el visual (IA o código), hace QA visual con visión, y te deja aprobar/publicar (con confirmación) desde un panel PWA.
