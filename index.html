¿Qué es esto? Un bot open-source que genera contenido de redes para cualquier marca con cualquier agente de IA (Claude Code, Codex, Gemini CLI, Qwen, Kimi, Cursor, Copilot, OpenCode, o un comando propio) o cualquier API de LLM (Anthropic, OpenAI, OpenRouter, DeepSeek, Groq, Ollama local…). Escribe el copy con el contexto de tu empresa, genera el visual (IA o código), hace QA visual con visión, y te deja aprobar/publicar desde un panel PWA.
